# Chronos-RPG: Rastreador de Iniciativa

Um rastreador de iniciativa premium para D&D e outros sistemas de RPG, focado em agilidade para o Mestre.

## ⚔️ Funcionalidades

- **Biblioteca de Personagens**: Salve seus jogadores e monstros frequentes.
- **Rolagem de Dados Inteligente**: Suporte para fórmulas como `1d20+3` e vantagens `2(1d20+2)`.
- **Adição em Massa**: Adicione múltiplos inimigos de uma vez (ex: 5 Orcs).
- **Gestão de PV e CA**: Acompanhe a saúde e a defesa de todos os combatentes.
- **Ordem Automática**: Organiza os turnos instantaneamente após a rolagem.
- **Persistência Local**: Todos os dados são salvos no navegador.

## 🚀 Como rodar

Como este é um projeto estático (HTML/CSS/JS), você pode:
1. Abrir o arquivo `index.html` diretamente em qualquer navegador.
2. Hospedar no **GitHub Pages** para acessar de qualquer lugar.

## 📥 Exportação de Dados

Você pode exportar e importar sua biblioteca de personagens em formato JSON, permitindo backups e compartilhamento entre dispositivos.
